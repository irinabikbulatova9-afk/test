# Вычисление среднего на R

Программа вычисляет арифметическое среднее переданных чисел. Сторонние R-пакеты не нужны.

## Локальный запуск

Нужен R 4.5.2 или совместимая версия.

```sh
Rscript mean.R 5 10 15
```

Результат:

```text
Среднее: 10
```

Если числа не передать, программа использует демонстрационный набор `10, 20, 30, 40, 50`.

## Запуск в Docker

```sh
docker build -t r-mean .
docker run --rm r-mean 5 10 15
```

Docker-образ фиксирует окружение на R 4.5.2.
