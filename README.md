# Небольшие программы на R

Проект содержит программы для вычисления среднего и корреляции. Сторонние R-пакеты не нужны.

## Локальный запуск

Нужен R 4.5.2 или совместимая версия.

```sh
Rscript mean.R 5 10 15
```

Результат:

```text
Среднее: 10
```

Если числа не передать, программа использует демонстрационный набор `10, 20, 30, 40, 50`.

### Корреляция

Передайте два ряда одинаковой длины, записав числа через запятую:

```sh
Rscript correlation.R "1,2,3,4" "2,4,6,8"
```

Результат:

```text
Корреляция Пирсона: 1.000000
```

Без аргументов скрипт использует демонстрационные данные.

## Запуск в Docker

```sh
docker build -t r-mean .
docker run --rm r-mean 5 10 15
```

Для запуска скрипта корреляции в том же образе:

```sh
docker run --rm --entrypoint Rscript r-mean /app/correlation.R "1,2,3,4" "2,4,6,8"
```

Docker-образ фиксирует окружение на R 4.5.2.
